# CleanYourMail App 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows 10/11 x64 PySide6 wizard for CleanYourMail that connects Gmail/Outlook/other providers, lets the person choose what to clean with checkboxes, reviews a reversible plan, applies it, and keeps undo one click away.

**Architecture:** A native PySide6 window drives a frozen `CleanYourMail 1.2.2` CLI sidecar built from the main repository tag. The app creates the config, stores app passwords in a private `password_file`, delegates the Microsoft device-code flow to the sidecar, and reads/writes only through the CLI JSON contract. The old 0.2.0 web UI is replaced.

**Tech Stack:** Python 3.12, PySide6 6.8+, pytest, pytest-qt, PyInstaller, Inno Setup 6, GitHub Actions on `windows-latest`.

**Spec:** `docs/superpowers/specs/2026-11-10-app-design.md`

## Global Constraints

- Windows 10/11 x64 only; app version `0.3.0`; sidecar pinned to CleanYourMail `v1.2.2`.
- PySide6 `>=6.8,<7`; no web view, no local server, no Electron/Tauri.
- The CLI is the only engine. The app never implements IMAP, planning, moves, undo or unsubscribe.
- No manual CLI path, TOML editing, or OAuth token field.
- No normal password; no secret in argv, QSettings, logs, error dialogs or test output.
- No write without a reviewed plan; undo stays available.
- Outlook copy: Microsoft 365 needs tenant admin consent; Outlook.com personal needs a verified publisher. Never claim otherwise.
- Local only: no account, cloud, telemetry or body access.
- English and Spanish are first-class; every string lives in `i18n/*.json`.
- The installer is per-user, no admin, and leaves `%APPDATA%\cleanyourmail-app`, `%USERPROFILE%\.secrets` and CLI state intact on uninstall.

## Review Focus

1. A saved app password is written to the wrong path, logged, or left in a widget after navigation.
2. The Microsoft device-code window is closed or the code copied incorrectly; the app must not poll forever or show a token.
3. A plan with zero moves or only unsubscribe actions reaches Apply; the review gate must stay closed.
4. The sidecar is missing or the wrong version; the app must fail closed before creating a config or changing mail.
5. The installer removes user secrets/state or needs admin; the uninstaller must leave them intact.

class CliError(RuntimeError):
    pass


class CliClient:
    def __init__(self, command: list[str], env: dict[str, str] | None = None) -> None: ...
    def run(self, args: list[str], *, config_path: Path | None = None,
